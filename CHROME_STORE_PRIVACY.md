## Single purpose description

Helps users check whether an image on the web is authentic or AI-generated by copying it and opening Google Gemini with a user-configurable verification prompt.

## Permission justifications

### storage
Saves the user's custom verification prompt (for example "is this true?" or a translation) so it persists across sessions and devices when sync storage is available.

### tabs
Finds or opens the Gemini tab, focuses it after the user clicks Verify, and coordinates the paste step on that tab only.

### scripting
Injects the on-page Verify UI on normal websites and the Gemini helper script when needed so the extension can show buttons and complete the paste flow after a user action.

### contextMenus
Adds a "Verify with Gemini" item to the right-click menu on images as an alternative to the on-page Verify button.

### clipboardWrite
Copies the user-selected image to the clipboard (as PNG) so it can be pasted into Gemini. The image is only copied after the user explicitly clicks Verify or the context-menu action.

### debugger
Attaches briefly to the Gemini tab the user already opened/focused in order to send a trusted paste (Ctrl+V) and insert the saved prompt. Gemini blocks ordinary scripted paste; the Debugger API is used only for that user-initiated paste step, then detached. No browsing data is collected or sent to our servers.

### Host permission (`<all_urls>` / broad host access)
Needed so the Verify button can appear on images across websites the user visits (social media, news, etc.) and so the extension can read the chosen image for clipboard copy after the user clicks Verify. The extension does not scrape pages in the background or upload page content to a developer backend.

### Remote code use
This extension does **not** execute remote code. All logic ships inside the extension package. It only opens the existing Google Gemini website (gemini.google.com) in a browser tab and interacts with that tab after a user gesture. No external scripts are downloaded or eval'd.

If the form asks whether you use remote code: choose **No** (or the option that says you do not use remote code), and if a justification box still appears, paste the paragraph above.

## Data usage / certification

- Certify that your data usage complies with the Developer Program Policies (check the certification box).
- This extension does **not** collect, sell, or transmit user content to a developer-operated server.
- Image data stays on the user's device / clipboard and is only sent to Google Gemini by the user through Gemini's own site after they click Verify.
- The only persisted setting is the user-defined prompt text in Chrome storage.

Suggested certification wording if a free-text field exists:

We do not collect or transmit personal user data to our own servers. The extension stores only the user-configured prompt locally in Chrome storage. Images selected by the user are copied to the clipboard and pasted into Google Gemini in the user's browser after an explicit user action.
